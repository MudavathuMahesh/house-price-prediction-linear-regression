# House Price Prediction using Linear Regression

## About

This project predicts house prices using a Linear Regression model with Python and Scikit-learn.

This is Task 1 of my Machine Learning Internship at SkillCraft Technology.

## Technologies Used

* Python
* Pandas
* Scikit-learn
* Google Colab

## Dataset

The project uses the Ames Housing dataset (`train.csv`).

## Features Used

* GrLivArea
* BedroomAbvGr
* FullBath

**Target:** SalePrice

## Model

Linear Regression

## Model Evaluation

* MAE: 35,788.06
* RMSE: 52,975.72
* R² Score: 0.6341

## How to Run

1. Download the notebook from this repository.
2. Open it using Google Colab.
3. Upload the `train.csv` dataset when prompted by the notebook.
4. Run the cells in order.

## Project Files

* `House_Price_Prediction_Task_1.ipynb` — Jupyter notebook containing the code and results.
